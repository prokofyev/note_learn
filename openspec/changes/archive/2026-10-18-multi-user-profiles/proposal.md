## Why

Сейчас приложение хранит ровно один профиль в `~/.note_learn_profile.json`, поэтому все, кто занимается на одном компьютере (например, брат и сестра или ученик и родитель), вынуждены делить одни и те же звёзды, серию и освоенность нот. Это искажает адаптивный курс: прогресс одного ребёнка подтягивает этапы и ноты другому, а счётчики мастерства перестают отражать реальные навыки.

## What Changes

- Профили становятся множественными: можно **добавить** нового пользователя (с именем), **переключиться** на другого и **удалить** ненужного.
- Прогресс по курсу (этапы, ноты, мастерство, звёзды, XP, серия, режим «С трубой / Без трубы») хранится **отдельно для каждого пользователя** и загружается при переключении.
- Появляется хранилище профилей в `~/.note_learn/` с индексом `users.json` (список пользователей + активный) и отдельным файлом на каждого пользователя; существующий одиночный `~/.note_learn_profile.json` при первом запуске **переносится** в профиль по умолчанию без потери прогресса (не разрушающе, исходный файл остаётся на месте).
- В интерфейсе появляется экран «Пользователи» с кнопкой в верхней панели: список пользователей, активный помечен, есть создание (ввод имени), переключение одним нажатием и удаление с подтверждением.
- Активный пользователь показывается в верхней панели рядом со статистикой.
- Удаление последнего оставшегося пользователя запрещено — в системе всегда есть хотя бы один активный профиль.
- Существующие вызовы `PlayerProfile.load(...)` / `profile.save(...)` и сигнатура `TrumpetLearningApp(save_path=...)` сохраняют обратную совместимость, чтобы не ломать тесты и внешнее использование.

## Capabilities

### New Capabilities
- `user-profiles`: управление несколькими пользователями (создание, переключение, удаление, отображение активного) и раздельное хранение прогресса обучения по каждому пользователю, включая миграцию одиночного профиля.

## Impact

- `note_learn/profile_store.py` (новый модуль): хранилище профилей, индекс `users.json`, создание/переключение/удаление/переименование, миграция legacy-файла.
- `note_learn/curriculum.py`: `PlayerProfile.load`/`save` получают совместимую сигнатуру; профиль перестаёт быть единственным на процесс.
- `note_learn/app.py`: `AppScreen.USERS`, активный профиль вместо фиксированного `save_path`, экран управления пользователями, кнопка в верхней панели, переключение профиля «на лету».
- `main.py`: без изменений в CLI, использует хранилище по умолчанию.
- Тесты: новые `tests/test_profile_store.py` + обновления `tests/test_app.py` (экран пользователей), `tests/test_curriculum.py` (совместимость load/save).
- Данные: новый каталог `~/.note_learn/`; `~/.note_learn_profile.json` читается только для миграции.
