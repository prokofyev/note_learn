# Школа юного трубача (`note-learn`)

Интерактивная обучающая программа для начинающего трубача (в строе **Си-бемоль / B♭** с русской нотацией *До, Ре, Ми, Фа, Соль, Ля, Си*).

## Возможности
- **Унисон с реальной трубой Си-бемоль (B♭)**: сэмплы `assets/trumpet/trumpet_60..84.ogg` автоматически звучат на 1 тон ниже написанной ноты (-2 полутона), в точности совпадая со звучанием трубы B♭.
- **Интерактивный нотный стан**: скрипичный ключ, добавочные линейки, целые, половинные и четвертные длительности, знаки диез, бемоль и бекар из `assets/accidental_*.png`.
- **Тренажёр трёх помп (аппликатуры)**: плавная анимация нажатия вентилей `[1] [2] [3]` мышкой или тремя пальцами правой руки на клавишах `J / K / L`, `1 / 2 / 3` или `Ф / Ы / В` (`0` — открыть все помпы).
- **От простого к сложному + интервальное повторение (Spaced Repetition)**: 6 этапов курса и 5 видов заданий с автоматическим возвратом к простым нотам для закрепления.
- **Практика с живой трубой через микрофон**: переключатель «С трубой / Без трубы», живой тюнер («Ниже / Точно / Выше») и шкала удержания нужной длительности ноты.
- **Несколько пользователей**: каждый ученик занимается под своим профилем — звёзды, серия, этапы и освоенность нот хранятся отдельно и не смешиваются.

## Профили пользователей

При обычном запуске приложение хранит профили в каталоге `~/.note_learn/`:

- `users.json` — список пользователей и активный профиль;
- `profiles/<id>.json` — прогресс конкретного ученика.

Кнопка с именем активного пользователя в верхней панели открывает экран управления профилями:

- **Добавить**: «Добавить пользователя» (или `[Enter]`) открывает поле ввода имени; `Enter` создаёт профиль с чистым прогрессом, `Esc` отменяет. Пустое имя не принимается, а одинаковые имена дают разные профили с независимым прогрессом.
- **Переключить**: «Переключить» у нужной записи сразу загружает прогресс этого пользователя.
- **Удалить**: «Удалить» требует подтверждения (кнопка меняется на «Точно?»). Последнего оставшегося пользователя удалить нельзя.

При первом запуске существующий одиночный профиль `~/.note_learn_profile.json` автоматически переносится в профиль по умолчанию; исходный файл остаётся на месте и не изменяется.

Если приложение запущено с явно указанным `save_path` (например, в тестах или скриптах), оно работает в прежнем режиме одного профиля по этому пути без создания каталога `~/.note_learn/`.

## Запуск

```bash
uv run python main.py
```

Приложение открывается в полноэкранном режиме: полотно вёрстки 1180×760 масштабируется на весь экран.
Переключить полноэкранный и оконный режим можно клавишей `F11` (в любой момент, без перезапуска).
`Esc` по-прежнему возвращает на карту курса, а на карте — завершает приложение.

Скрипичный ключ на нотном стане отрисовывается из рисунка `assets/GClef.png` (масштабируется с сохранением
пропорций и выравнивается по второй линейке «Соль»). Если файл отсутствует, используется встроенный
векторный запасной вариант.
